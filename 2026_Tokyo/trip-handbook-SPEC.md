# 旅遊手冊製作規格(分享版)

> 這份文件描述一種「單檔、離線、手機優先」的團體旅遊手冊該有哪些功能,以及開工前要準備哪些資料。
> 把這份文件連同你的行程資料一起交給 Claude,它會照規格幫你做出一份手冊。
> 外觀(配色、字體、版面)由 Claude 自行設計,你可以在開工指令裡寫下想要的風格。

---

## 〇、開工指令(貼給 Claude 的第一段話)

```
附件是旅遊手冊製作規格,以及這趟的行程資料。
請照規格做一份單檔 HTML 旅遊手冊 {檔名}.html:

1. 第二節的功能全部做出來;標「可選」的依我在第一節勾的決定要不要做。
2. 外觀風格:{例:日式和風、簡潔白底、深色模式…},字要大、按鈕要好按。
3. 行程資料從附件整理;不確定的地方先列出來問我,不要自己猜航班、住宿、分攤規則。
4. 營業時間、班次、票價這類會變的資訊,能查證的先查證,並標註查證日期。
5. 做完照第四節的檢查清單逐項確認,再交給我。
```

## 二、功能規格

### 2.1 整體

- **一個 HTML 檔案**,所有內容都在裡面,沒有網路也能打開。不引用任何外部字體、圖示庫或程式庫
- **手機直式優先**:字要大、按鈕要夠大好按;電腦打開時改成比較寬的版面
- **主要分頁**:行程、地圖、交通、住宿、清單
- **次要頁面**(放在標題列的圖示按鈕):導覽、緊急、天氣、優惠
- 標題列顯示手冊名稱(可以點擊修改)與日期

### 2.2 行程頁

- 一天一頁,最上方一排日期可以左右滑動切換
- 每天最上面:第幾天、日期星期、這天的標題與區域
- **重要提醒**用醒目的色塊顯示在當天最上方(例:只有 A 組今天飛、這天是當地連假、這家店要先預約)
- 當天項目依時間排列成時間軸。每個項目有:
  - 時間、名稱、一行副標
  - 類型(景點、吃飯、移動、住宿、航班、提醒),用不同顏色的圓點區分,頁面底部附顏色說明
  - 小標籤(例:3 號出口、步行 5 分、L.O. 14:00、週三公休)
  - 備案(例:下雨時改去哪裡),可以點開地圖
  - 摺疊的詳細提醒,平常收起來,點開才看
  - 右邊一個打勾按鈕,走完就勾,下次打開還記得
- **點地點名稱直接開地圖**:手機優先開 Google 地圖 App,沒裝就開網頁版;電腦開新分頁。另外提供切換成 Apple 地圖的選項
- 地圖查詢用**當地語原名**(畫面上顯示中文),中文店名丟進 Google 地圖常常找不到
- 最重要的一兩個項目(例:回程機場快線)可以特別標示
- **精簡模式**:一個按鈕切換成只看時間和地點,副標、標籤、提醒全部收起來,適合在路上快速確認
- **自己加項目**:浮動按鈕「變更行程」,可以選日期、時間,加上自己的項目與備註,跟原本的行程排在一起

### 2.3 地圖頁(可選)

- 用 SVG 畫簡化的離線示意圖:全程總覽圖、市中心圖,加上需要的區域放大圖
- 地點依實際經緯度擺放;畫出會搭到的鐵道,附路線名稱與顏色
- 可以選某一天,把那天的路線畫出來,並附一句說明
- 手機上可以雙指縮放、雙擊放大
- 地名標籤不能互相壓到,也不能壓到站點
- 註明「示意用,別拿來導航」

### 2.4 交通頁

分四個子分頁:

- **航班**:各組航班卡片(出發、抵達、飛行時間、提醒),時間、訂位代號、座位可以在手機上直接改並記住
- **接駁**:各組怎麼從機場進市區、最後一天怎麼去機場,附官方訂票連結
- **訂票**:出發前要先訂的票與預約,照處理的先後排序,標明「最優先/出發前/現場買」
- **會合**:第一天在哪裡會合、最後一天怎麼解散

### 2.5 住宿頁

- 每間住宿一張卡片:名稱(點了開地圖)、入住退房日期、晚數、誰住
- **當地語完整地址**,一鍵複製(給計程車司機看)
- 訂房代號、門鎖密碼(可能有好幾組,例:大樓門、房門),各自一鍵複製
- 住宿備註:離車站多遠、門鎖怎麼開、垃圾怎麼丟、緊急聯絡電話
- 換宿日的行李怎麼處理

### 2.6 清單頁

分四個子分頁:

- **購物**:自己加的待買清單(可新增、打勾、刪除),加上照地點分組的必買清單,顯示已買進度
- **行李**:分組的打包清單(必帶證件、這趟特殊裝備、電子、藥品、出發前 24 小時待辦),可勾選、顯示完成進度
- **花費**(可選):每人會用到的交通與門票費用,自動加總出大概範圍;整團分攤的費用(例:租車)另外標示,不算進每人總數
- **分攤**:每筆住宿與代付款項的總額、怎麼分,自動算出每人該付多少。總額可以在手機上直接改並即時重算。每一列要寫出算式(例:12,000 × 1/2 ÷ 2 人),最後列出加總過程,讓大家對帳看得懂

### 2.7 次要頁面

- **導覽**:最上方放免責聲明(「資訊由 AI 整理,時刻與營業時間請出發前再查證」),接著用幾段文字說明手冊怎麼用、組別怎麼切、存檔有什麼限制
- **緊急**:當地報警與救護電話、觀光客熱線、我國駐外館處、外交部急難救助專線、護照與物品遺失怎麼辦、天災應變;號碼要能直接點擊撥打;另外留幾個欄位讓人自己填信用卡掛失與保險電話
- **天氣**:連到當地氣象網站各地區的預報頁,加上這個季節要注意的天氣與穿著建議
- **優惠**(可選):商店優惠券。券圖直接內嵌在檔案裡,離線也能給店員掃;附一個 EAN-13 條碼產生器,輸入 13 位數字就產生可以掃的條碼

### 2.8 分組

- 標題列有組別切換按鈕;只有一組時不顯示
- 切換後,行程、提醒、住宿、分攤、交通頁的內容都換成那一組的版本
- 大家共用的項目所有組都看得到,只有某一組的項目只給那一組看
- 按鈕下方一行小字說明現在看的是哪一組、有誰

### 2.9 儲存與備份

- 所有勾選、自訂項目、手動修改的欄位都存在手機瀏覽器裡,關掉再開還在
- 每份手冊用自己獨立的儲存名稱,同一支手機開兩份手冊不會互相覆蓋
- **iPhone 的限制**:用 Safari 直接從「檔案」App 開本機 HTML 時,瀏覽器儲存會被擋。要:
  - 偵測到這個狀況時顯示提示條,說明原因和解法
  - 提供「**存成新檔**」:把目前所有狀態寫進一份新的 HTML 檔下載,下次開那份就接得上
  - 提供「**匯出/還原文字**」:把狀態變成一段文字,可以貼到備忘錄或傳給同行的人,之後貼回來還原

## 三、內容撰寫原則

- **會變的資訊都要查證並標日期**:營業時間、公休日、最後點餐時間、班次時刻、票價、優惠券效期
- **公休日遇國定假日**,很多店會照常營業。寫「可能照開,先打電話」,不要直接判定關門
- 排進行程的店,確認開門時間對得上抵達時間
- 同一個城市有名稱相近的車站時,每個項目都寫清楚是哪一站、哪個出口
- 報到截止、末班車這類「過了就來不及」的時間要特別醒目
- 每個住宿都要有當地語完整地址
- 資料更正後直接改成正確的,不要在手冊裡留「更正說明」

## 四、完成前檢查清單

- [ ] 斷網打開,所有頁面都正常
- [ ] 每一組、每一天、每個分頁都切過一次,沒有錯誤
- [ ] 各組看到的項目數量合理,沒有看到別組專屬的內容
- [ ] 分攤頁每人金額手算一次對得上
- [ ] 點幾個地點名稱,地圖查得到正確的店
- [ ] 手機寬度截圖檢查:文字沒有被切掉、長網址不會撐破版面、地圖標籤沒有互相壓到
- [ ] 勾選、自訂項目關掉重開還在;「存成新檔」和「匯出/還原」各試一次
- [ ] 搜尋整份檔案,沒有留下範例文字或空白連結

## 五、旅行中的更新

- 行程有變動時,把新的安排告訴 Claude,請它更新手冊並重新交付整份檔案
- 查證過、推翻原本資料的事實(例:這家店其實週二休),另外記在一份筆記裡,之後改版才不會被改回去
